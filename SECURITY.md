# Security policy

Security fixes are maintained on `main`. Older commits are not separate
supported release lines. Consumers should pin a reviewed commit and validate
it with their supported Netty and application versions.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/pjscruggs/netty-raknet/security/advisories/new).
Include the affected revision, a minimal reproduction, impact, and any proposed
fix. Do not put exploit details, credentials, private captures, or operational
records in public issues. Coordinate public disclosure after a fix is available.

For a problem specific to Minecraft integration, identify the affected
Raknetify2 version in the same private report so the fix can be coordinated.
